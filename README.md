# youtube-analyze — разбор YouTube-канала в Claude Code

> Напиши Claude «проанализируй мой канал» — он пройдёт по роликам и комментариям, найдёт, что залетело и что просело, и скажет, о чём снимать и что писать в Telegram дальше.

Это не дашборд с цифрами. Цифры нужны только как доказательство, а на выходе — выводы и готовые идеи.

## Что умеет

- Находит самые залетевшие ролики и просевшие, объясняет закономерности.
- Читает комментарии: что просят и о чём спрашивают зрители.
- Выдаёт идеи следующих видео: заголовок, как искать тему, превью, срочность, источник.
- Выдаёт идеи постов для Telegram-канала.
- Предлагает 3 фрагмента из лучшего видео для Shorts.
- Сравнивает с другим каналом и разбирает одно видео («почему не пошло»).
- Ничего не выдумывает: если данных нет, так и пишет.

## Установка

Две команды в терминале, потом перезапусти Claude Code:

```bash
claude plugin marketplace add yearofcodeking/youtube-analyze
```

```bash
claude plugin install youtube-analyze@youtube-analyze
```

Обновление: `claude plugin marketplace update youtube-analyze`. Удаление: `claude plugin uninstall youtube-analyze@youtube-analyze`.

## Что нужно заранее

Для чтения данных YouTube скиллу нужен MCP-сервер и бесплатный ключ YouTube Data API v3. Node.js 18+ должен быть установлен (`node -v`).

**Ключ (минут 10):**
1. Зайди на console.cloud.google.com и создай проект (название любое).
2. «APIs & Services» → «Library» → найди **YouTube Data API v3** → «Enable».
3. «APIs & Services» → «Credentials» → «Create credentials» → «API key».
4. Открой созданный ключ («Edit API key») и в «API restrictions» оставь только YouTube Data API v3.
5. Скопируй ключ.

Если Google недоступен из твоей сети, включи VPN на весь компьютер (не только в браузере).

**Подключение сервера.** При первом запуске скилл сам расскажет про ключ и даст готовую команду, ключ в чат вставлять не нужно. Команда для Windows (замени `ВСТАВЬ_КЛЮЧ` на свой):

```bash
claude mcp add youtube --transport stdio --scope user -e YOUTUBE_API_KEY=ВСТАВЬ_КЛЮЧ -- cmd /c npx -y @kirbah/mcp-youtube
```

На macOS и Linux то же самое, но вместо `cmd /c npx` пиши `npx`. После перезапуска проверь командой `claude mcp get youtube`: нужен статус «Connected».

Проверить, что всё подключено, можно запросом `/youtube-analyze настройка`.

## Как пользоваться

- `/youtube-analyze` — полный разбор канала: что залетело, что просело, идеи для видео и для Telegram
- `/youtube-analyze идеи для видео` — только идеи роликов
- `/youtube-analyze идеи для постов` — только идеи постов для Telegram-канала
- `/youtube-analyze комментарии` — что просят зрители
- `/youtube-analyze шортсы` — 3 фрагмента из лучшего видео для Shorts
- `/youtube-analyze сравни с @канал` — сравнение с другим каналом
- `/youtube-analyze почему не пошло <ссылка на видео>` — разбор одного ролика

Можно и обычными словами: «разбери мой канал», «о чём снимать дальше», «что просят в комментариях».

Квота ключа — 10 000 единиц в сутки, скилл расходует её экономно и предупреждает, если вызов дорогой.

## Как устроено

```
youtube-analyze/
├─ .claude-plugin/marketplace.json            каталог (чтобы ставилось одной командой)
└─ plugins/youtube-analyze/
   └─ skills/youtube-analyze/
      ├─ SKILL.md                             порядок работы: подключение, сбор, анализ, выдача
      └─ NOTICE.md                            благодарности открытым проектам, на идеях которых он построен
```
